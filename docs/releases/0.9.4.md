# AirSIM Apps v0.9.4

AirSIM Apps v0.9.4 adds a real “Local only” mode that is independent of cloud infrastructure. When it is on, iPhone and Android pairing exchanges only the VoWLAN local secret. It does not require a Relay address, a device cloud identity, or an APNs token. iOS also stops PushKit, CallKit, and cloud ActivityKit token registration, so push authentication problems do not block LAN pairing.

## Main changes

- The iOS first-connection page and Settings add a “Local only” switch. Turning it on forces cloud mode off and disables the cloud switch, the Relay address, and the cloud self-check.
- The local pairing payload contains only `local_mode`, `cloud_enabled=false`, and the VoWLAN secret. It no longer depends on Relay, the device Secret, a PushKit/APNs token, a Bundle ID, or the APNs environment.
- While local mode is running, PushKit, APNs, CallKit, and remote Live Activity token registration stop. Turning local mode off restores system registration. Cloud mode is still turned on manually by the user.
- Both Android Standalone and the older AVF Agent recognize `local_mode`, forbid local mode from turning Relay back on, and treat a local pairing as a complete valid configuration.
- The iOS dialer removes the duplicate title and the separate VoWLAN banner. The content is centered and compressed onto one page, with no scrolling.
- The lock-screen Live Activity and Dynamic Island include the current Android device name, number, Standalone/AVF type, pairing count, and VoWLAN/cloud status.

## Android update

1. Download `AirSIM-Android-Standalone-0.9.4.apk` and check the SHA-256 on this page and the release-certificate SHA-256.
2. Overwrite Standalone with `adb install -r` or the system installer. The package name remains `com.airsim.phonecontrol.standalone` and does not overwrite the older AVF app.
3. After turning on “Local only” on the iPhone, pair again. Android saves the VoWLAN secret and stops Relay heartbeats and cloud command polling.
4. To restore cloud features, first turn off “Local only” on the iPhone, then turn cloud mode on manually and pair again so Android receives the full cloud identity and Push parameters.

## iOS IPA re-signing

The public IPA is an unsigned build. It contains no development certificate, provisioning profile, or device UDID, and cannot be installed directly. Use your own Apple Developer Team to configure the Bundle ID, signing, and provisioning profile separately for the main app, Watch App, and Live Activity Extension. If you need cloud mode, your Relay `ALLOWED_BUNDLE_ID` and APNs topic must also match the main app. Full steps are in the [iOS README](../../iOS/README.md).

## Security boundary

Local mode does not bypass VoWLAN's six-digit pairing code, encrypted exchange, HMAC, timestamp, or nonce checks. The public APK/IPA does not contain an APNs private key, Dashboard token, Cloudflare token, AVF control token, Android release private key, or Apple signing identity. AirSIM cannot replace the system emergency-call capability.
