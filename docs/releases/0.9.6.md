# AirSIM Apps v0.9.6

This release completes local and cloud orchestration for Android Standalone, and focuses on reliability for real incoming calls, SMS, network switching, and the iPhone Live Activity. The AVF Agent remains the independent `v0.4.6`. This Apps Release adds an AVF Bridge APK so devices that still use the Linux Agent can upgrade in place.

## Main changes

- Android Standalone supports a local mode that does not depend on Relay, PushKit, or CallKit. While local mode is on, the cloud switch cannot be operated, and VoWLAN control and PCM call audio remain.
- Android adds an optional `READ_SMS` scan fallback, a dedup cursor, and a recent-delivery record, reducing the chance of missed SMS when a vendor system drops the SMS broadcast.
- Android incoming calls provide a lock-screen full-screen page and notification actions for answer, reject, and hang-up, and strengthen Telecom call-target selection, mute retry, PCM listener recovery, and process keep-alive.
- The iPhone dialer shows the current Android phone, phone number, Standalone/AVF, VoWLAN, and cloud status together, and supports a list of multiple paired Agents with automatic fallback.
- iPhone local mode no longer blocks pairing because Relay registration, the PushKit token, or cloud status failed. Cloud status is queried only when the app opens, before dialing, and before the Live Activity appears.
- After a VPN turns off or the network path changes, iPhone actively restores VoWLAN. The Live Activity gains a display switch, and the compact/expanded layout and progressive Liquid Glass background are redesigned.
- Fixes a case where, after Android had already ended an incoming call, iOS received a delayed CallKit hang-up callback, retried incorrectly, and then showed “Neither the local link nor cloud voice is reachable.”
- Relay moves high-frequency heartbeats and device state into Durable Objects, and adds cloud-control idempotency, timeout rescue, multi-Agent routing, and a quota-degradation path.

## Install and verification

The AVF Bridge package name is `com.airsim.phonecontrol`. The Standalone package name is `com.airsim.phonecontrol.standalone`. Both use the same official Android release certificate, but they cannot overwrite each other. The public IPA contains no Apple signature or provisioning profile and cannot be installed directly or submitted to TestFlight. The official maintainer build uses `com.eric3u.airsim`, production APNs, and App Store Connect distribution signing.

Before release, Android AVF/Standalone, AVF Agent, Relay, and iOS tests were run, and both APKs were checked for version, release signature, and `debuggable=false`, along with signatures of the main app, Watch App, and Live Activity Extension in the iOS Release archive. A physical Samsung phone and iPhone Air were used for local incoming-call, hang-up, VoWLAN, and Live Activity regression. Other carriers and device models still need separate acceptance.
