# AirSIM Apps v0.9.2

AirSIM Apps v0.9.2 is the first release of the Android Standalone APK. The AVF Agent's Relay heartbeats, cloud commands, device identity, status API, and media orchestration are merged into the Android foreground service. A new install no longer needs Linux Terminal, Debian, the AVF private network, `8575/8576`, or `airsim-installerd`. The older AVF Linux Agent [v0.4.5](https://github.com/kai-wu-cortex/AirSIM/releases/tag/v0.4.5) remains for compatibility and fallback.

## Main changes

- The built-in Android Agent handles Relay registration, 30-second heartbeats, WebSocket/HTTP commands, device state, Push, and single-path cloud PCM orchestration. Status reads use an in-process interface.
- The Android Bridge splits the Agent `send_sms` command from Telecom call operations, so it does not incorrectly enter call-ID checks and produce `active call id mismatch`.
- Before sending SMS, it checks system permission, SMS capability, and the default SMS SIM. It sends segments through the Android system SMS service and reports the result to the Agent only after each segment's system send receipt. A receipt does not mean the recipient has received the message. After a timeout, check first so the message is not sent twice.
- When Xiaomi HyperOS cannot open the default-phone role picker, the APK completes the role setup automatically after the user has authorized Shizuku. At startup it cleans up leftover old PCM Bridge processes.
- Non-Samsung Android selects call uplink and downlink through the system `TYPE_TELEPHONY` audio device. Samsung continues to prefer the voice TX route. A Xiaomi HyperOS device has verified that call audio plays on the iPhone.
- Each iOS PCM TCP reconnect generates a new handshake nonce, so the server does not treat the reconnect as a replay and produce `cycle failed`.
- iOS SMS notifications accept the Agent's nanosecond-precision timestamps and use `delivery_id` to align the push with the local synced copy. Tapping an SMS notification opens the sender's conversation, and a cold start still keeps the navigation request.
- This release does not add Samsung system incoming-SMS broadcast collection. The iOS notification path still requires that Android/Agent has already created and uploaded the corresponding SMS event. Do not treat outbound-SMS acceptance as full bidirectional SMS acceptance.

## Android update

1. Download `AirSIM-Android-Standalone-0.9.2.apk` and check the SHA-256 on this page and the release-certificate SHA-256.
2. Standalone uses the separate package name `com.airsim.phonecontrol.standalone`. It can coexist with the older AVF app, but it does not inherit the old package's pairing data. Record the Relay, device ID, and pairing information before installing.
3. Start Shizuku and authorize AirSIM Standalone, grant phone, SMS, and notification permissions, then set it as the default phone app. If the HyperOS system page is unavailable, return to the app and let it finish setup automatically.
4. Let only one AirSIM package hold the default phone role and the PCM session at a time. After Standalone is verified, the AVF Agent can be stopped. Clearing AVF/Debian data is not an install step.
5. On the iPhone, verify dial, answer, hang-up, bidirectional audio, and SMS separately. After the SMS system receipt, the recipient still needs to confirm that the message actually arrived.

## iOS IPA re-signing

The public IPA is an unsigned build. It contains no development certificate, provisioning profile, or device UDID, and cannot be installed directly. Use your own Apple Developer Team to configure the Bundle ID, signing, and provisioning profile separately for the main app, Watch App, and Live Activity Extension, and make your Relay `ALLOWED_BUNDLE_ID` and APNs topic match the main app. Full steps are in the [iOS README](../../iOS/README.md).

## Verification scope

- Android Standalone, Bridge/CoreTests, iOS simulator tests, Agent/Installer/Relay regression tests, and packaging checks passed.
- The official Android APK is `0.9.2 (74)`, `minSdk 29`, `targetSdk 35`, `debuggable=false`. The release signature matches v0.9.1, and `apksigner verify` passed.
- The iOS Release `iphoneos` build and IPA ZIP integrity check passed. The main app, Watch App, and Live Activity extension are all `0.9.2 (74)`. The IPA contains no code signature or provisioning profile.
- A Xiaomi HyperOS device has verified Standalone's default phone role, VoWLAN pairing, and call-audio routing. The SMS send path was previously tested successfully with a development build of the same code, and the recipient confirmed receipt. The officially signed v0.9.2 APK still needs an install retest. Foreground, lock-screen, cold-start, and cloud-mode iOS SMS notifications have not finished end-to-end acceptance.

## Security boundary

This project is limited to the noncommercial uses allowed by the license. The APK/IPA does not contain an APNs private key, Dashboard token, Cloudflare token, AVF control token, Android release private key, or Apple signing identity. AirSIM cannot replace the system emergency-call capability.
