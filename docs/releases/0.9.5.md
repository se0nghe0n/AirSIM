# AirSIM Apps v0.9.5

This release fixes Android Standalone not receiving carrier SMS, and improves SMS send wait, incoming-call reject, microphone authorization, and local-call audio uplink recovery. The AVF Agent remains the independent `v0.4.6`. The Relay protocol is unchanged.

## Main changes

- Both Android run modes add a carrier `SMS_RECEIVED` receiver and `RECEIVE_SMS` permission. Standalone persists received SMS and serves it to the iPhone `/api/sms` endpoint and event stream. AVF mode also keeps SMS waiting to be forwarded when the Agent is temporarily offline.
- Standalone records local acknowledgement and Relay delivery separately, so an SMS is not dropped after the iPhone has acknowledged it but before the cloud has received it.
- The local SMS send wait window follows the Android system receipt and the AVF Agent's maximum execution time, so the iPhone does not report a timeout while Android is still processing.
- iOS requests microphone permission the first time it enters the foreground, instead of waiting until re-pairing or call audio starts.
- Android reject prefers the ringing incoming call. If the call is already connected, it hangs up, and it accepts a call the system has already removed as end confirmation.
- The DTMF sheet uses Liquid Glass keys, with press highlight, scale, and haptic feedback.
- Send errors on the iPhone local PCM microphone uplink are no longer ignored silently. They trigger a bounded reconnect. Diagnostic stats count only frames that were sent successfully.

## Install and verification

The Android Standalone package name remains `com.airsim.phonecontrol.standalone` and can be installed over the existing app with `adb install -r`. After upgrading, open the Android app and allow the new “Receive SMS” permission. Without that permission, carrier SMS will not be received.

The public IPA contains no Apple signature or provisioning profile and cannot be installed directly or submitted to TestFlight. Configure your own Bundle ID, Team, and profiles for the main app, Watch App, and Live Activity Extension. Cloud mode also requires matching Relay/APNs credentials. See the [iOS README](https://github.com/kai-wu-cortex/AirSIM/blob/v0.9.5/iOS/README.md).

Android Standalone/Core tests, iOS simulator tests, and the iOS Release `iphoneos` archive all passed. The APK is `0.9.5 (78)`, `minSdk 29`, `targetSdk 35`, `debuggable=false`, and `apksigner verify` passed. No usable Android or iPhone device was connected at release time, so carrier SMS, real incoming-call reject, and bidirectional audio still need retesting on actual devices and networks. This release does not claim that voice-routing limits have been removed on every device model.
