# AirSIM AVF Agent 0.4.6-1

This release syncs the Agent protocol changes required by the Android Standalone and iPhone multi-Agent/local-mode work into AVF Linux, and strengthens call control and Relay recovery.

## Main changes

- Pairing registration adds the Android Agent identity, type, device name, manufacturer, model, and phone number. Heartbeats sync these fields so the iPhone can display and choose a route among multiple Android Agents.
- Local-mode registration is supported. Local mode does not require Relay, PushKit, CallKit, or cloud device parameters, and it forces the cloud command and push paths off.
- VoWLAN answer, reject, and hang-up can carry `call_id`. The Agent rejects an expired or mismatched call ID so a delayed notification does not control the next call.
- The cloud-command WebSocket adds tiered backoff reconnect, so a short outage or a VPN switch no longer reconnects to Relay at a high rate.
- Cloud hang-up adds call-end confirmation and retry, reducing the chance that the iPhone has already hung up while Android is still ringing or still in the call.
- The Debian build works with both GNU tar and BSD tar. The first-install script still supports non-destructive recovery and re-pairing of an existing install.

## Install and update

First install or service recovery:

```sh
bash -o pipefail -c 'curl -fsSL --connect-timeout 10 --max-time 90 --retry 2 --proto =https --proto-redir =https --tlsv1.2 https://github.com/kai-wu-cortex/AirSIM/releases/download/v0.4.6/install-avf.sh | sudo sh'
```

A device that already has `0.4.5-1` and a healthy installerd can update to `0.4.6-1` directly from the Android AirSIM AVF management page. A device still on `0.4.4-1` must first follow the [AVF installation guide](../AVF_INSTALL_GUIDE.md) and run the one-time trust-root migration. It cannot use the in-app update directly.
