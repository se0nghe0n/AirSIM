# AirSIM AVF Agent 0.4.4-1

This release lets AirSIM coexist with an existing DJOneHub in the same Android AVF Linux, and fixes first-install and status-identification problems. Before publishing, every Debian asset must be signed with the existing Ed25519 release private key. A successful build cannot stand in for signing or on-device verification.

## Changes

- The AirSIM Agent listens on `8575`, and the independent installerd listens on `8576`. It does not stop or take over DJOneHub's `7575`.
- Agent `/api/health` returns `product=airsim`. The Android app, installerd, and first-install script check the product identity so another service is not mistaken for AirSIM.
- The Android app migrates an old AirSIM `:7575` configuration to `:8575` and uses the new private-network port for automatic discovery.
- The first-install script checks Debian dependency state and AirSIM port conflicts first. If system packages are already broken or a port is in use, it exits before installing. On a repeat run it prefers restoring the existing service and keeps the rollback package.
- AVF install, pairing, and non-destructive troubleshooting docs are updated.

## Checks before installing on a coexistence device

1. In AVF Linux, confirm `sudo apt-get check` succeeds. If `udev` and `libudev1` disagree, first simulate and check the repair plan in the [installation guide](../AVF_INSTALL_GUIDE.md).
2. Confirm DJOneHub on `7575` is healthy, and that `8575` and `8576` are not occupied by other processes.
3. Confirm the downloaded signed package version is `0.4.4-1`, and that the embedded release public key matches the previous release. Do not run the old `0.4.3` online install script in a coexistence environment.
4. After install, verify DJOneHub `7575`, AirSIM Agent `8575` (`product=airsim`), and AirSIM installerd `8576` separately, then pair and run a real call test.

## One-tap install

Run this in the AVF Linux Terminal:

```sh
bash -o pipefail -c 'curl -fsSL --connect-timeout 10 --max-time 90 --retry 2 --proto =https --proto-redir =https --tlsv1.2 https://github.com/kai-wu-cortex/AirSIM/releases/download/v0.4.4/install-avf.sh | sudo sh'
```

The install script always downloads the signed v0.4.4 package and checks system dependencies and port conflicts before installing. If the download fails, do not switch to the old v0.4.3 script.
