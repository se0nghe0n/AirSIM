## Main changes

- The Android status page now reads real Agent, Push/Relay, VoWLAN, PCM, and Shizuku state, and provides expandable redacted diagnostics.
- Dial, answer, reject, hang-up, and DTMF explicitly check the default phone role before they run, so commands do not land on DJOneHub or another phone app.
- VoWLAN ready status requires both the Agent and PCM handshakes to complete, reducing false “the UI shows ready but the voice path is not up” judgments.
- The Android Debug page adds filtering, error emphasis, and a more complete recent-event display.
- iOS outgoing-call routing tightens Samsung VoWLAN/cloud selection and failure boundaries.
- The AirSIM Relay has moved to the independent `https://airsim-push.remotepilot.site`. The current `/healthz` protocol version is `0.2.0`. DJOneHub continues to use `https://push.remotepilot.site`.

## Android install

1. Download `AirSIM-Android-0.9.0.apk` and check its SHA-256.
2. If the device has an old debug-signed package, record the pairing information and uninstall the old package first.
3. Install the APK and set AirSIM as the Samsung default phone app.
4. Start Shizuku, authorize AirSIM, then reconnect the AVF Agent.
5. Verify dial, answer, hang-up, SMS, VoWLAN, and bidirectional PCM separately.

## iOS IPA re-signing

The public IPA is an unsigned build. It contains no development certificate, provisioning profile, or device UDID, and cannot be installed directly. Re-signing must handle all of the following:

- Main app: replace `com.example.airsim` with a Bundle ID you control.
- Watch App: the main Bundle ID plus `.watchkitapp`.
- Live Activity Extension: the main Bundle ID plus `.liveactivity`.
- Sign the main app, Watch App, and Extension with your own Apple Developer Team, certificates, and provisioning profiles.
- In your own Relay, set `ALLOWED_BUNDLE_ID` to the new main Bundle ID and configure the matching APNs `.p8`.
- Set your own `AIRSIM_PUSH_RELAY_URL`. The maintainer Relay accepts only `com.eric3u.airsim`.

After re-signing, verify PushKit, CallKit, APNs sandbox/production, background incoming calls, and cloud PCM on a physical iPhone/Apple Watch. A successful unsigned IPA build does not mean those on-device paths have passed.

## Security boundary

This project is limited to the noncommercial uses allowed by the license. The APK/IPA does not contain an APNs private key, Dashboard token, Cloudflare token, AVF control token, Android release private key, or Apple signing identity. AirSIM cannot replace the system emergency-call capability.
