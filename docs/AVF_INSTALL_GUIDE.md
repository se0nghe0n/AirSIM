# AVF installation retired

This source tree no longer provides the AVF Agent, installer, bootstrap or Linux recovery paths. Use [Android Standalone](../android-standalone/README.md).

Existing device data is not removed or automatically imported. Preserve AVF files and pending SMS until Standalone has been paired and verified. Do not uninstall, clear app data, or purge the Linux package as part of a source update. See [the Standalone migration and preservation contract](standalone-migration.md).

Historical release notes describe their original releases; they are not current installation instructions.
